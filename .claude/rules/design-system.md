# Ledger — the app + extension design system

`packages/design-system` is **Ledger**, exported from the Claude Design project
and the single source of truth for the aiBytes_ **web app and Chrome
extension**. The newsletter is not a consumer — see the newsletter rule for why.

- The design brief in `docs/aibytes-design-system-brief.md` wins on conflicts,
  then the product spec in `docs/aibytes-app-product-spec.md`.
- **Tokens are authored CSS**, not generated. `styles.css` imports `tokens/*.css`
  in order; there is no build step and no `dist/`. The old `tokens.json` →
  `npm run build:tokens` pipeline was retired with the Bitmark-era Web
  Components — do not reintroduce it.
- Components are **React 18 JSX** with relative imports and no bundler
  assumptions. Each carries a `.d.ts` and a `.prompt.md` stating its intent;
  update all three together.
- `_ds_manifest.json`, `_ds_bundle.js`, `_adherence.oxlintrc.json`, `.thumbnail`,
  and the `<!-- @dsCard … -->` first-line markers on the `*.card.html` and
  `ui_kits/**` files are the Claude Design round-trip surface. They are
  generated by that app — preserve them, never hand-edit them, and keep the
  marker line first in any preview file you add.

## Theming, and the one gap left for injected UI

Ledger was authored for a page we own. Fix gaps in the package, not by forking
it downstream:

- Dark mode follows the OS: the dark tokens sit under `[data-theme="dark"]` and
  again under `prefers-color-scheme: dark` for `:root:not([data-theme="light"])`.
  The two blocks must match; `tests/test_design_system.py` fails if they drift.
- Tokens land on `:root` only (the open item in AIB-76n). Inside a content
  script's shadow root, `:root` is the host page's `<html>` and carries none of
  them, so injected UI needs the same declarations on `:host` plus its own
  reset — a host page guarantees neither sane `box-sizing` nor neutral
  typography. The new-tab page is the extension's own page and is unaffected.

## Non-negotiables

Text is the interface (images are 40px accents). One accent (`--accent` cobalt)
for interaction, `--hot` only for "top today" and the HN tile, `--save` only in
the filled star. Mono with tabular numerals on every number. 1px borders, no
shadows at rest, no gradients or glass. Same layout in both themes — only the
palette flips. AA contrast and a visible 2px focus ring everywhere.
