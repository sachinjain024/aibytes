Decided · 03 Nov 2026

Layout 4, ranked lists. It's the quietest page and reads like an article, which suits Substack. Position shows the rank, so the stat can sit quietly at the end of the row. It uses no callout, highlight or code chip, so a paste needs no hand fixes.

The current website theme stays. That's the cream background #FFF7ED, orange accent #FF6719 and Spectral body text, all already set on the publication, so the theme doesn't change. The web post is cream. The email preview shows a white sheet with orange links, an orange blockquote bar and an orange Subscribe button.

Rules that carry forward: H2 per section, with its emoji. The lead story is an H3 with its linked title, then a paragraph and a divider. Ranked sections (Viral on X, New AI products, Trending GitHub projects, HN deep stories) are numbered lists with the stat last, in body text, since coloured text doesn't survive a paste. The (Source) labels are body text too, and attribution links take the accent like every other link. A pull quote closes AI News. Official announcements are an H3 per company, a blockquote, and a link line. A spaced hyphen goes between a name and its description, never an em dash. One Subscribe button sits after the sign-off.

Works, and survives a paste

  • Headings H1 to H6, bold, italic, links, bullet and numbered lists
  • Blockquote with a bar in the accent colour
  • Callout block, a tinted box (div.callout-block)
  • Pull quote, centered italic between two rules
  • Highlight in any colour, so signal yellow #FFD338 works
  • Inline code as a mono chip, plus the divider

Doesn't work

  • Tables are flattened to one line of text when pasted
  • Coloured text exists in the editor but is lost on paste, so it has to be set by hand
  • Custom CSS or HTML isn't available anywhere in settings
  • Mono and display fonts can't be used in the email. Its body comes out as a serif.
  • A second link colour. Every link is the accent.

What this means for the next items

  • Item 5, publishing: the skill can write one Substack-ready HTML file. You copy it and paste it into the editor once, then add the button and social image by hand.
  • Item 7, backfill: Settings → Import has a Beehiiv post importer built in.
  • Item 8, audience: there's a separate welcome email for imported subscribers, which can double as the platform-move note.
  • Alias: replies come from aibytesnewsletter@substack.com. "Forward reader emails to" is where contact@aibytes.io goes.
