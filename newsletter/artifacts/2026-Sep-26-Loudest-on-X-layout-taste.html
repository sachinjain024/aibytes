V3 - Ticker rows, with a heart for likes

Why this one. It matches Products, GitHub and HN, so the section looks native on day one and stays the shortest block in the issue. Each row is the author's name and the post's first line, verbatim, linked to the post on X.

Amended on selection: a heart, not the word "likes". The stat column reads ♥︎ 13.3k, in the same slot and style as Products' ▲ 776. The heart is written as U+2665 plus the text selector U+FE0E, so iOS Mail draws it in the text colour instead of swapping in a red emoji.

Amended: about two lines per post, ending in a grey … A row shows the post from its start, with each line break shown as a grey /, up to 140 characters of the post: about two lines in the 640px column. If the post is longer, it stops at the last word break inside that and ends with a grey …, so it is clear there is more on X. Nothing is reworded. The count is a character budget rather than a CSS line clamp, because Gmail ignores line clamps and Beehiiv snippets carry inline styles only; on a phone the same text runs to three or four lines.

The most editorial, and the loudest type in the issue. Setting the posts in the display face makes them read as quotations, which suits a section built on people's own words. Two costs: 17px display type across five posts outweighs the news card above it, and lowercase, casually typed posts like #2 look odd set that large. The numerals also imply a ranking, which here is by likes, not by my judgement.

Three smaller calls

  1. Where it sits: decided. After the AI News card and the Official Announcements card, before Products. Both cards are unnumbered (see the Official Announcements sheet), so Loudest on X is 0x02 and Products, GitHub and HN move to 0x03–0x05.
  2. The #2 post is out: decided. zero's motion-design post opened with "f*cking", so it left the shortlist and Deedy's research-paper-to-video post (5.4k likes) took its place, after Elon Musk's post (promoting his own company's Grok 4.7 harness) and donaldjewkes's (its "full prompt:" had no prompt) were skipped. Standing rule from here: no posts with profanity, starred out or not, in the Grok prompt and the shortlisting rules. The other specimens still show the original five.
  3. Likes as the only stat. The specimens show likes rounded to one decimal of a thousand. Grok's like counts ran up to 12% below what X showed, and its repost counts were further off, so reposts and views stay out. Rounding also hides a count going stale between Friday's fetch and Monday's send.

Why not X's own embed? X embeds need X's script, and Beehiiv snippets can't run scripts. An embed added in Beehiiv's editor would sit outside our HTML snippet and look like X rather than aiBytes_.
